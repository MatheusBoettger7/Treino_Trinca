# Treino Trinca

Aplicativo de treinos com catálogo de exercícios em PT-BR.

## Imagens dos exercícios

A branch de teste usa as ilustrações flat do RepDB para manter o visual original do catálogo que já era utilizado no aplicativo. As imagens são armazenadas localmente no aplicativo para evitar depender do servidor externo durante o uso.

**Exercise data by [RepDB](https://repdb.co)**

As imagens e os dados do RepDB são usados conforme a licença do free tier, que permite uso dentro de aplicações com atribuição. O projeto não deve ser tratado como um novo dataset ou API de exercícios.

## Branch de teste

A implementação desta etapa está em teste/exercicios-ptbr. A main não faz parte desta alteração.
